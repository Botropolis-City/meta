## Why it is not a measurement

- **The window was never hidden**: the box had no `xprop` or `xwininfo`, so `perf-city` never found the window (`window_at_start=unknown`) and could not hide it at 14,400 s ([item 309](../../roadmap/309-the-soak-box-cannot-hide-the-city.md), which added them and a pre-flight).
  So there is no hidden phase, and the visible phase is the whole run.
- **"The visible phase drew no frames" is wrong**: the city drew 863,640 frames (`frames_at_end`).
  `perf.py`'s `judge_soak` counts `frames_at_hide` whenever a hide was asked for, and a hide that failed never writes it, so it reads 0.
  When the hide failed, the visible phase is the whole run and `frames_at_end` is its count.
- **The monitor's state is unknown**, for the same missing tools.
